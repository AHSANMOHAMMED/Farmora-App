# 🛠️ 3-Step Assembly Guide in CapCut or Canva

1. **Generate the 8 clips:** Copy each 10-second prompt into **Google Flow / Veo / Kling AI** and download `Scene_01.mp4` through `Scene_08.mp4`.
2. **Timeline Assembly:** Drop all 8 clips in order onto a CapCut or Canva timeline (Total runtime: 80 seconds).
3. **Voiceover & Captions:** 
   - Record or generate the voiceover sentences using **ElevenLabs** (or CapCut's built-in text-to-speech).
   - In CapCut, click **Auto Captions** ➔ Style them in green/white typography.
   - Add a subtle corporate ambient background track at -18dB volume.
   - Export final high-definition **MP4** for submission!
